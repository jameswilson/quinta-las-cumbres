# Quinta Las Cumbres

Tiny static navigation landing page for guests.

Production URL:
https://www.elementalidad.com/quinta-las-cumbres/

Destination:
-2.791370, -78.936028

## GitHub Pages

Publish this repository with GitHub Pages using the repository root as the site source, then configure the existing elementalidad.com setup so this repo is served at `/quinta-las-cumbres/` in the same way as the other elementalidad sub-sites.

The QR code should always point to the production URL rather than directly to Waze or Google Maps, so the destination/buttons can be changed later without reprinting the QR.
